Featured projects

The websites mentioned below are running on a VPS (virtual private server), using Debian GNU/Linux. More info about what a VPS is can be found from sources such as Wikipedia, AWS, and Google Cloud.

I'm using several measures to keep my VPS secure, including the unattended-upgrades package, which automatically installs security updates on a regular basis, and restarts the VPS in the early hours of the morning if required.

Using a VPS to run my web applications has taught me some valuable things about deploying and running web applications. I'm using systemd to run the binary of the EmojiBoard project below, and systemd is also used to run Nginx and FPM (FastCGI Process Manager) for the Laravel Test project below.

EmojiBoard

Code: github.com/bt1k/emojiboard

React TypeScript Go

EmojiBoard is a very simple website which allows you to submit emojis for others to see. Submitted emojis are stored in a PostgreSQL database. Features include:

  • Rate limiting to reduce server load in the event of many requests.
  • Database check constraint to ensure only certain emojis can be submitted.
  • Database trigger function to ensure that a maximum of 10 emoji posts are in the database at any time (to prevent unlimited growth of database size).

Laravel Test

Code: github.com/bt1k/laravel-test

PHP Laravel

Laravel Test is a basic website I made to improve my knowledge of PHP and Laravel. It uses a PostgreSQL database. Features include:

  • Validates data on the back-end, so that only certain text inputs will be saved into the database.
  • Uses front-end JavaScript to submit an HTTP DELETE request when a button is clicked to delete a post.
  • Deployed using Nginx and FPM (FastCGI Process Manager).

Other projects

The websites below can each take around 1 minute to load. I am using free hosting on Render which puts websites to sleep when inactive.

New Rails Blog

Ruby Rails

New Rails Blog is a simple blog website made with Ruby on Rails and a PostgreSQL database. Features include:

  • The Trix WYSIWYG text editor for writing rich text blog posts.
  • User authentication, which is required to submit a blog post.
  • Integration with Cloudinary to host images submitted within blog posts.

The reason for "new" in the name is because I made this website to replace a previous inferior blog website which I also made with Rails.

PostBoard

JavaScript Node.js Preact

PostBoard is similar to EmojiBoard above, but instead of submitting only emojis, you can submit text messages. Features include:

  • Google's Gemini artificial intelligence API is asked, with a suitable prompt, whether each submitted text message is offensive. Offensive messages are not saved.
  • Back-end written with Node.js, the web framework Express, and the Prisma ORM.
  • Preact is used on the front-end. It's a lightweight alternative to React, but the developer experience is nearly identical.
